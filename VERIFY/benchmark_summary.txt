STRUE Benchmark Summary

Structural Truth Engine

Benchmark Scope

Query-time property retrieval using maintained current structure.

Comparison performed against recursive filesystem traversal.

All measurements below are descriptive observations from the STRUE reference environment.

These are reproducible demonstrations.

These are not universal guarantees.

Environment

- Offline execution
- Stdlib Python implementation
- Maintained current structure enabled
- Explicit synchronization model
- Query-time retrieval benchmark scope

Representative Benchmark Results

~3 us

~10,000,000x

Observed Behavior

- structural lookup remains approximately flat across tested scales
- traversal increases with object count
- identical structure produced identical observable truth
- maintained structure enabled query-time retrieval without recursive traversal
- benchmark behavior remained consistent across repeated runs

Benchmark Interpretation

STRUE does not claim traversal elimination.

Traversal still exists for:

- initialization
- synchronization
- verification
- recovery
- release validation

The benchmark explores a narrower question:

Does query-time property retrieval fundamentally require traversal when maintained current structure already preserves truth?

Core Invariant

truth_visible iff structure_updated

same structure -> same truth

same structure -> same certificate
